# Employee Activity Recognition and Productivity Analysis

## Project Overview

This project is a Computer Vision pipeline for analyzing human activity in video and generating activity and productivity information for tracked people.

The system combines person detection, multi-object tracking, action recognition, object detection, body-pose estimation, temporal analysis, and activity classification.

The system classifies the activity state of tracked people into:

```text
WORKING
NOT_WORKING
NEUTRAL
```

## Project Goal

The system is designed to answer the following questions:

1. Where are the people in the video?
2. Which frames belong to the same person?
3. What action is the person performing?
4. What objects are near or associated with the person?
5. What is the person's body pose?
6. How should the combined information be classified?
7. What are the working ratio and productivity statistics generated by the system?

## Person Detection

YOLO11 is used to detect people in video frames.

The detection stage provides bounding boxes that are passed to the tracking stage.

## Person Tracking

BoT-SORT is used to track people across video frames.

The tracking stage maintains a consistent identity for each detected person across consecutive frames.

Example:

```text
Frame 100 -> Person 1
Frame 101 -> Person 1
Frame 102 -> Person 1
Frame 103 -> Person 1
```

## Stable Person ID

An additional stable-ID mechanism is used to reduce identity changes during tracking.

The process can use information such as:

* Previous bounding box
* Motion prediction
* Distance between detections
* Bounding-box smoothing
* Missing-frame tolerance

Example:

```text
person_1
person_2
person_3
```

## Person Sequences

Tracked people are converted into short temporal sequences.

These sequences are used as input for the action-recognition stage.

## Object Detection

Object detection provides additional context about a person's activity.

Examples of relevant objects include:

* Laptop
* Keyboard
* Mouse
* Cell phone
* Book
* Bottle
* Cup

Detected objects can be associated with nearby tracked people.

## Pose Estimation

MediaPipe Pose is used to estimate body-pose information.

Pose information provides additional context for activity analysis.

## Feature Fusion

The system combines information from multiple sources:

```text
SlowFast Action
       +
Object Detection
       +
Pose Estimation
       ↓
Feature Fusion
```

The combined information is used by later activity-analysis stages.

## Temporal Smoothing

Frame-level predictions can temporarily change because of detection or recognition noise.

Temporal smoothing is used to reduce unstable short-term changes and produce more stable activity states over time.

## Productivity Analysis

The system generates productivity-related statistics from the final activity timeline.

Example metrics include:

* Person ID
* Total frames
* Working frames
* Not Working frames
* Neutral frames
* Working Ratio
* Productivity Percentage

## SlowFast Evaluation

The evaluated SlowFast model produced the following results:

| Metric    |     Result |
| --------- | ---------: |
| Accuracy  | **77.88%** |
| Precision | **75.22%** |
| Recall    | **76.30%** |
| F1 Score  | **74.08%** |

### Important Metric Difference

The following values represent different concepts:

```text
SlowFast Accuracy = 77.88%
Working Ratio     = 85.28%
Productivity      = 93.71%
```

The **77.88%** value is the evaluated accuracy of the SlowFast action-recognition model.

It is **not** the accuracy of the complete Working / Not Working system.

Working Ratio and Productivity are system-generated statistics based on the final activity decisions.

## Evaluation Limitation

The available action labels contain:

```text
Class_ID
Start_Frame
End_Frame
```

They do not contain:

```text
Person_ID
```

Therefore, these labels are suitable for evaluating the action-recognition task, but they are not sufficient by themselves to calculate a validated end-to-end accuracy for:

```text
WORKING
NOT_WORKING
NEUTRAL
```

An independent person-level Ground Truth dataset would be required for a validated end-to-end evaluation.

## Limitations

### Person Tracking

Tracking can be affected by:

* Occlusion
* Detection failures
* Similar-looking people
* Fast movement
* Long periods without detection

### Action Recognition

The current evaluated SlowFast Action Accuracy is:

```text
77.88%
```

Some action classes can be confused with visually or temporally similar actions.

### Activity Rules

The final activity state depends on predefined activity rules and available evidence.

Changing these rules can change the final activity distribution and productivity statistics.

### Productivity

The reported productivity percentage is calculated from the system's own final decisions.

It is not an independently validated measurement of real-world employee productivity.
